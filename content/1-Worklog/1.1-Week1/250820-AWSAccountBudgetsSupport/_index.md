### Overview

This note records the study session about AWS Account setup, AWS Budgets, and AWS Support. These topics help prepare a safe learning environment before deploying AWS resources.

### AWS Account

* Reviewed the AWS account sign-up process.
* Learned about root user responsibility and why it should be protected.
* Prepared for later labs by identifying where account and billing settings are located.

After reviewing the account setup flow, I noted that the root user is powerful and should not be used for normal daily tasks. The account should be protected first, then IAM users or roles should be used for lab work.

### AWS Budgets

* Studied how AWS Budgets can track monthly usage and estimated charges.
* Reviewed budget alerts and notification settings.
* Noted that budgets should be created early in a learning account.

For a learning account, the budget does not deploy any application, but it is still important. It helps me notice unexpected usage early, especially when I start creating resources such as EC2 instances, VPC components, or storage services.

### AWS Support

* Reviewed how to find AWS Support Center.
* Learned the difference between account, billing, and technical support cases.
* Checked where support plans and documentation links are located.

I also checked the support workflow so I know where to go if there is a billing issue or account access problem. This is useful preparation before doing more labs.

### References Checked

* AWS Study Group labs for AWS Account, AWS Budgets, and AWS Support.
* AWS Cost Management documentation about creating budgets.
* AWS Console pages for account, billing, and support navigation.

### Summary of Today's Learning

1. **Cost awareness**: AWS Budgets is important for learning accounts.
2. **Account safety**: The root account should be protected and rarely used.
3. **Support workflow**: AWS Support provides a path for account or billing problems.
